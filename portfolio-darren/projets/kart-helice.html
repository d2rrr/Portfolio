KART à hélice

Un projet technique autour de la réalisation électronique d’un KART à hélice, de la conception aux tests de fonctionnement.

Présentation

🏎️ Présentation du projet

Le projet KAH consiste à concevoir l’électronique d’un KART à hélice piloté à distance.

Objectif du projet

Réaliser un système capable de recevoir des commandes depuis une manette et de piloter les actions principales du KART : avancement, direction et klaxon.

Architecture du système

Le système repose sur deux cartes électroniques complémentaires : une carte émetteur intégrée à la manette et une carte récepteur installée sur le KART.

Cartes électroniques

🎮 Carte émetteur

Intégrée à la manette, elle sert d’interface homme-machine pour piloter simplement le KART.

📡 Carte récepteur

Installée sur le KART, elle reçoit les commandes et les transforme en actions : avancement, direction et klaxon.

Répartition de l’équipe

Final

🏁 Résultat final

Le projet a permis de relier électronique et informatique autour d’un système embarqué concret.

La conception, la fabrication, la programmation et les vérifications nous ont montré comment une carte émetteur envoie des commandes et comment une carte récepteur les traite pour piloter un système réel.

Le groupe a obtenu un KART fonctionnel avec son émetteur de commande, répondant aux exigences du cahier des charges.

Le KART a ensuite été testé lors d’une course organisée dans le cadre du projet, ce qui a validé le fonctionnement global en situation concrète.

Conception

Bloc énergie

J’ai travaillé sur l’alimentation de la carte émetteur afin de respecter le cahier des charges. L’objectif était d’assurer au moins 1 heure d’autonomie, en estimant la consommation avec une marge de sécurité. Avec le plus petit accumulateur disponible, l’autonomie estimée atteignait environ 5 heures. Un régulateur et un interrupteur ont aussi été ajoutés pour obtenir une alimentation stable et simple à utiliser.

Conception

Informatique récepteur

J’ai travaillé sur le programme du récepteur, qui analyse la trame infrarouge envoyée par l’émetteur. Le programme vérifie d’abord que la trame est valide pour éviter une mauvaise réaction du KART. Il extrait ensuite les informations utiles : numéro d’équipe, klaxon, direction et vitesse. Ces données permettent de piloter le servomoteur et le moteur.

Fonction de traitement récepteur

// Definition des fonctions de traitement

bool Securite(int8_t ValeurErreur) {  // Retourne : 0 (état de la trame invalide), 1 (état de la trame valide)
  return !ValeurErreur;
}

uint8_t ExtraireNumeroEquipe(uint8_t Adresse) { // Retourne la valeur du numéro d'équipe extraite de l'octet Adresse
  return (Adresse & 0b01111111);
}

uint8_t CalculerDirectionServomoteur(uint8_t Donnee) { // Retourne une valeur : [ 0 ; 180 ]
  return ((Donnee & 0b00011111) * 180.0 / 30);  // Retourne la valeur de la direction convertie en angle
}

uint8_t CalculerVitesseMoteur(uint8_t Donnee) { // retourne une valeur : [ 0 ; 180 ]
  return ((Donnee >> 5) * 180.0 / 7);  // retourne une valeur de signal PWM à partir de la valeur vitesse extraite dans l'octet Donnée
}

uint8_t ExtraireEtatBuzzer(uint8_t Adresse) { // retourne : 0 (inactif), 1 (actif)
  return (Adresse >>7);
}

Conception

Schéma final et routage

Après la conception des différents blocs, nous avons regroupé les éléments dans le schéma électrique final sur Proteus ISIS. Cette étape a permis de vérifier la cohérence du montage de la carte émetteur avant fabrication. Le routage a ensuite été réalisé sur Proteus ARES afin de placer les composants et de créer les pistes du circuit imprimé.

Fabrication

Carte émetteur

Après la validation du schéma et du routage, nous avons fabriqué la carte émetteur. Les étapes principales ont été l’impression du typon, l’insolation, la gravure, le nettoyage, le perçage et la soudure. Un contrôle à l’ohmmètre a permis de vérifier la continuité des pistes, puis un contrôle final a validé le sens des composants, leurs valeurs et la qualité des connexions.

Fabrication

Carte récepteur

La carte récepteur a suivi les mêmes grandes étapes de fabrication que la carte émetteur. Le typon a été imprimé, puis la plaque a été insolée afin de transférer le tracé des pistes. Après la gravure et le nettoyage, la continuité a été vérifiée à l’ohmmètre. La carte a ensuite été percée, soudée, puis contrôlée pour valider le montage.

Vérification

Traitement récepteur

Après la fabrication de la carte récepteur, nous avons vérifié les fonctions de traitement. Le récepteur devait réagir uniquement lorsqu’une trame valide était reçue : dans ce cas, la LED de connexion bleue indiquait que la trame était correcte. Nous avons aussi contrôlé que les informations de la donnée NEC étaient bien interprétées pour piloter les commandes principales : vitesse du moteur, direction du servomoteur et klaxon.

Mobilisation

  • Oscilloscope
  • Test des commandes
  • LED de connexion
  • Klaxon
  • Servomoteur

Vérification

Énergie récepteur

Pour la partie énergie du récepteur, l’objectif était de vérifier que le KART respectait l’autonomie minimale demandée. Le cahier des charges imposait au moins 15 minutes avec une batterie LiPo 2S. Une alimentation de laboratoire a été utilisée pour simuler la batterie, puis la consommation a été mesurée avec le moteur à mi-puissance. L’autonomie estimée était d’environ 40 minutes.
